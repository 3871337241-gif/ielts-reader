# IELTS Reader · 剑雅 4–20 阅读库

网站：[打开阅读器](https://3871337241-gif.github.io/ielts-reader/)。按“剑雅 → Test → Passage”选择原文，涵盖 17 册 Academic、204 篇阅读。剑雅 1–3 按用户要求不收录；剑雅 12 保留原书 Test 5–8 编号。

## 使用

- 阅读目录、原文阅读、生词本三个入口；题目练习与错题本已从界面移除。
- 标题和正文英文词均可点击；基础功能词默认弱化。词卡独立弹出，外部点击关闭，保留阅读位置。
- 收藏按原形合并，跨文章共用生词本。保留来源原句，可跳回原文；支持翻卡、已掌握状态和复习次数。
- 每篇独立保存进度，支持继续阅读、上一篇/下一篇、完成标记与字号调整。
- 划词翻译：点击「划词翻译」，长按或拖选几个单词/整句，再点击「翻译所选」。独立弹窗显示所选原文和中文；「退出划词」恢复单词点击。电脑也可直接拖选。翻译来自 MyMemory 在线接口，仅发送所选原文，不发送生词本或学习记录。已有结果在当前浏览器缓存；额度/网络异常显示重试提示。
- 旧版本收藏和阅读位置自动迁移；旧浏览器存储中的原答题记录不会被覆盖。
- 支持 JSON 学习备份与导入。下载未开始时，可复制界面显示的完整备份文本另存为 JSON。
- 发音调用设备 SpeechSynthesis，优先英国英语声音并请求 en-GB；实际输出取决于设备已安装语音。词卡另有 Cambridge Dictionary 链接。

## 原文与词典来源

用户提供的 20 个 PDF 文件只读处理，SHA-256 核对均未改变；完整 PDF 未上传。网页每篇提供对应原书页面裁切图，方便逐句对照。

204 篇由原书文本提取及 Apple Vision OCR 整理，修正了双栏顺序、标题/副标题、段落字母和发现的漏行。目录与篇数、来源图片、唯一锚点及 87 篇的完整字母编号均通过自动检查；204 篇已逐篇在网页打开并核对英文点击数量。**尚未对全部 204 篇进行人工逐字校对，可能仍有 OCR 标点、拼写或段落边界误差。** 原始 Cambridge IELTS 13 Test 3 Passage 3 的 A–H 正文继续使用此前逐页核对的数据。

新文章词卡常见中文义、词性与原形来自 [ECDICT](https://github.com/skywind3000/ECDICT)，MIT 许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。覆盖 15,121 / 16,090 种正文词形；专名及未收录词明确标为待核实。新文章显示“词典释义 · 请结合原句”，不声称已逐句审核语境义。原有首篇已审核的语境词义及长句讲解保留。

不强行生成词根词缀或同义替换；无法确认的解释明确留空说明。中文注释不是原书译文。

## 本地运行与检查

纯静态 HTML / CSS / ES modules，无后端。仓库根目录运行 `python3 -m http.server 8000`，访问 http://localhost:8000/ 。

Node.js 22 或更新版本运行 `npm test`。14 项测试覆盖分词、跨文章进度、旧数据迁移、备份恢复、无效输入以及翻译分段、请求参数、额度错误和取消；内容检查覆盖 17 册、204 篇、175,133 个正文可点击词元、来源图片及唯一锚点。实测详情见 [TEST_RESULTS.md](TEST_RESULTS.md)。

`content/library.json` 为目录索引，`content/book-*.json` 为原文，`content/lexicon.json` 为词典，`content/originals/` 为原书对照图。`verification/library-sources.json` 保存来源和哈希记录，`scripts/` 保留只读整理工具。原始 PDF 和临时 OCR 缓存不在仓库内。

## GitHub Pages

Settings → Pages → Deploy from a branch → main / (root)。资源使用相对路径；`.nojekyll` 禁用 Jekyll。GitHub Actions 在提交与 PR 上运行语法、单元和内容检查。

学习记录存于当前浏览器，不自动跨设备同步；清理浏览器数据前请备份。手机尺寸已实测，真实 iPhone Safari 硬件、英国英语音频输出和系统文件下载仍需设备验收。
